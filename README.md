# C-Cpp-SFML-Game-Jam
Join the game jam by 11/01/2026 to participate! It ends on 01/31/2027. Voting happens from 02/01/2027 to 02/28/2027. Top three winners are declared on 03/01/2027.

1. Joining:
   Create a fork of this repository for you to work with. When done, submit it in a branch (I'm not really familiar with Git software, so do whatever is necessary).
2. Participating:
   You must follow the theme of Retro. You will be judged. Use SFML3.1.0 and C23/C++26 to create your game. You must have a Game.cpp, .h class declarations, and .cpp class definitions.
3. Voting:
   When we get to this stage in February of 2027, each person will submit the top three favorites and their username for GitHub at the top.
4. Winning:
   On 03/01/2027, I will carry out a short playthrough of each of the top three games listed by the most people. The number one game will be the winner, the owner earning the pride of winning since I do not have any money for you all, sorry.
5. Cheating:
   * If you do not use SFML3.1.0 or C23 and C++26 (they must be up to date), it is considered cheating and you will be eliminated at voting.
   * If you are disrespectful, you will be eliminated immediately.
   * If you copy someone else's work, both you and the person you copied will be eliminated prior to voting.
   * Using documentation is okay and will not be punished.
   * Watching YouTube tutorials is completely inappropriate and will be punished with elimination.
   * Anything unofficial to C/C++ or SFML is not allowed.

Thank you for taking the time to read the above before entering the competition!
